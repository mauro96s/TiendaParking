HU-01: Registro de Ficha de Viaje

Como Encargado de Registro
Quiero capturar y almacenar en una estructura de datos externa los datos del carro, del motor, del chofer y del pasajero
Para tener centralizada toda la información de un viaje en un único registro

Criterios de Aceptación:
1. El sistema debe permitir ingresar los datos del carro: placa, marca y modelo.
2. El sistema debe permitir ingresar los datos del motor: número de serie y tipo.
3. El sistema debe permitir ingresar los datos del chofer: cédula, nombre completo y licencia.
4. El sistema debe permitir ingresar los datos del pasajero: cédula y nombre completo.
5. Toda la información se debe guardar temporalmente en una estructura de datos externa antes de ser enviada a la base de datos.
6. El Encargado de la Base de Datos es el responsable de validar que los 4 conjuntos de datos estén completos antes de confirmar el guardado.
